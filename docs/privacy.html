개인정보 처리방침 (yt-auto)

시행일: 2026-11-05

  1. 목적: yt-auto는 운영자 본인이 소유한 유튜브 채널에 영상을 업로드하고 업로드 결과를 확인하는 용도로만 사용됩니다.
  2. 접근하는 정보: Google OAuth를 통해 승인된 유튜브 채널의 기본 정보(채널 이름·ID)와 업로드 권한만 사용합니다.
  3. 저장: 인증 토큰은 운영자의 비공개 실행 환경에만 저장되며 제3자에게 제공·판매하지 않습니다.
  4. Google API 사용: yt-auto의 Google API 정보 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다. 또한 YouTube 서비스 약관과 Google 개인정보처리방침이 적용됩니다.
  5. 권한 철회: Google 계정 보안 설정에서 언제든 접근 권한을 철회할 수 있습니다.
